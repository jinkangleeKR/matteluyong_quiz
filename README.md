# 현장 퀴즈

## 데모

### [데모 열기](https://jinkangleekr.github.io/matteluyong_quiz/preview.html)

1. 왼쪽 관리자 화면에서 퀴즈를 만들고 저장합니다.
2. **새 게임방 · QR 만들기**를 누르면 오른쪽 참가자 화면이 같은 게임방에 자동 연결됩니다.
3. 오른쪽에서 닉네임을 입력해 대기실 입장, 채팅, 답안 제출과 결과 공개를 순서대로 확인합니다.
4. 처음부터 다시 하려면 상단의 **테스트 데이터 초기화**를 누릅니다.

테스트 화면은 Firebase의 실제 퀴즈·게임방 데이터를 사용하지 않고, 현재 브라우저에만 임시로 저장됩니다.
