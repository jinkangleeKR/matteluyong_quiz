# 현장 퀴즈

QR 코드로 참가자가 접속하는 퀴즈 사이트입니다. 현재는 참가자가 대기하는 첫 화면을 제공합니다.

## 참가자 QR 코드

아래 QR 코드를 스캔하면 참가자 대기 화면으로 이동합니다. 인쇄하거나 화면에 띄울 때는
SVG 원본을 사용하세요.

[QR 코드 원본 열기 / 내려받기](qr-code.svg)

![퀴즈 참가 QR 코드](qr-code.svg)
